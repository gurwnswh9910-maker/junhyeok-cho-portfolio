# 직접 검토하는 여정 상태 관리

안늦었을지도의 원 구현에서 `journey-service.mjs`, `journey-store.mjs`를 내용 변경 없이 가져왔습니다. 파일 해시는 [출처 목록](../evidence/source-manifest.json)에 있습니다. 지도·경로 엔진 전체가 아니라 여정 진행과 영속 저장을 검토하는 범위입니다.

## 실행

Node.js 22.13 이상(검사 환경: Node.js 24.14.0). 추가 설치나 API 키는 필요하지 않습니다.

```sh
node code/review-check.mjs
```

저장소 루트에서 실행합니다. 검사는 스스로 종료하며 서버나 외부 네트워크를 사용하지 않습니다. 합성 경로·교통 응답을 사용하고 `code/.review-state/`에 임시 SQLite DB를 만든 뒤 자신이 만든 폴더만 정리합니다. `node:sqlite`의 실험 기능 경고는 Node 버전에 따라 표시될 수 있습니다.

## 확인하는 내용

- 승차 전 도착 처리 거부, 승차→하차→도착의 상태 순서.
- DB를 닫고 다시 열어도 여정·최초 예상·사용자 식별이 유지되는지.
- 같은 사건 중복 실행 방지, 오래된 상태 버전·잘못된 복원 토큰 거부.
- 15초 갱신 경계, 동시 새로고침의 중복 외부 작업 방지.
- 재탐색 실패 시 기존 안내 보존, 위치 없는 재탐색 거부.
- 미탑승 복구 뒤에도 최초 목표·예상 보존, 목표가 없으면 도착 목표 판정 `null`.

`review-check.mjs`는 공개 검토용으로 작성한 합성 검사입니다. 원 제품의 화면 변환기와 교통 제공자는 작은 대역으로 바꿨습니다. 실제 MCP 통신·지도 렌더링·교통 API·GPS 이동·운영 Firestore 검사를 대신하지 않습니다.
